# Night Bunker

A first-person zombie survival roguelite.

## Windows

1. Download **Night-Bunker-Windows.zip** from the [latest release](https://github.com/jfisher907-max/night-bunker-updates/releases/latest).
2. Unzip it, then double-click **Install Night Bunker.cmd**. If Windows shows "Windows protected your PC", click More info, then Run anyway.
3. Play from the Night Bunker shortcut.

After that the game updates itself: when a new release is posted here, the title screen shows **Update now**. One click and it restarts on the new version with your saves kept.

Each release carries `latest.json`, which the installed game reads to find new versions.
