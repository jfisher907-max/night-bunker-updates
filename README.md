# Night Bunker

A first-person zombie survival roguelite.

## Windows

1. Download **[Night-Bunker-Windows.zip](https://raw.githubusercontent.com/jfisher907-max/night-bunker-updates/updates/Night-Bunker-Windows.zip)** (always the newest build).
2. Unzip it, then double-click **Install Night Bunker.cmd**. If Windows shows "Windows protected your PC", click More info, then Run anyway.
3. Play from the Night Bunker shortcut.

After that the game updates itself: when a new build is posted here, the title screen shows **Update now**. One click and it restarts on the new version with your saves kept.

Builds live on the `updates` branch, replaced on each release. Its `latest.json` is what the installed game reads to find new versions.
